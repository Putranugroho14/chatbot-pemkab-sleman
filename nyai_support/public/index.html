🧠 Konsep Sistem Routing: S-Bot Super Agent vs Specialized Agent

Sistem S-Bot menggunakan Semantic Routing untuk memahami maksud (intent) warga, bukan sekadar kata kunci statis. Jika warga bermaksud mengurus dokumen kependudukan atau reservasi wisata, AI Router 🔀 secara otomatis mengalihkan alur percakapan ke Specialized Agent 🎯 yang mengeksekusi step workflow. Pertanyaan umum non-workflow akan ditangani oleh S-Bot Super Agent 🧠 berbasis RAGFlow / Knowledge Base lokal.

🧠 Super Agent
Pengetahuan Umum & RAG

Menjawab regulasi, visi misi, dan informasi umum dari dokumen resmi Diskominfo.

🔀 AI Router
Semantic Intent Classifier

Mendeteksi intensi warga dengan confidence score untuk mengarahkan ke alur yang tepat.

🎯 Specialized Agent
Step Workflow Executor

Mengumpulkan data, memvalidasi nomor WA/NIK, mengeksekusi API, dan menerbitkan tiket.
